# CampoLab · Física II · Unidad 3

Simulador grupal de corriente eléctrica y ley de Ohm para Ingeniería de Sistemas, grupo 2. Docente: Ramiro Manrique Rua. Universidad Peruana Unión.

## Abrir el simulador

Una vez habilitado GitHub Pages, el simulador estará disponible en:

https://jeffersonsnayderperez20-lgtm.github.io/Fisica-II-Unidad-3/

La página incluye los controles de circuitos en serie, paralelo y mixtos, el visualizador de la ley de Ohm y un panel para consultar el código fuente. El archivo `codigo-fuente.zip` contiene el proyecto editable en React y TypeScript.
